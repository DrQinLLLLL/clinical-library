Data Management

How it works: All changes made in this admin panel are saved to your current browser by default. Click "View Site" to preview instantly.
To make changes visible to all visitors, click "Export data.js" and replace the file on the server (or redeploy).
Data structure: Site data consists of settings (site settings), categories (category list), and articles (article list). Article fields include: title, English title, authors, journal, year, DOI, original link, category, tags, abstract, key findings, cover image, gallery images, featured flag, and visibility flag.
